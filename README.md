## 📱 Apps & Utilities

### 1. TimeKeeper - Routine & Habit Tracker
- **Overview:** An Android routine and habit tracking utility designed to keep daily routines consistent with precision alarms. Works completely offline with zero sign-up required.
- **Key Features:**
  - Custom routine schedules (Daily, Weekdays, Weekends, Specific days)
  - Visual streak counters & daily completion dashboards
  - Built-in timer and stopwatch
  - Offline-first local data storage (Privacy focused, No Login)
- **Platform:** Android Native App

### 2. DayCount (Coming Soon)
- **Overview:** An intuitive D-Day counter and milestone tracker to manage important anniversaries and goals.

### 3. ClipFlow (Coming Soon)
- **Overview:** A smart clipboard manager to organize, store, and quickly reuse frequently used text snippets.

### 4. FreshCue (Coming Soon)
- **Overview:** A smart expiry date assistant to monitor the freshness of pantry items and daily supplies.
