스마트 클립보드 상용구 복사기

  • ✓ 다른 앱 위에서 바로 뜨는 플로팅 퀵패드 1초 복사
  • ✓ 동적 변수({오늘날짜}, {클라이언트}) 자동 치환 템플릿
  • ✓ 온디바이스 AES 암호화로 계좌번호·비밀번호 안전 저장
